### Who Should Attend

Researchers who analyze biological data in R and want to run RStudio and Bioconductor packages on RCAC clusters instead of an overloaded laptop.

### What You’ll Learn

* How to start RStudio on RCAC clusters and request the right amount of memory and time
* What the r-bioconductor environment provides and how to add packages of your own
* How to move an analysis from an interactive RStudio session to a batch job when it outgrows the session

### By the End of the Session, You’ll

* Run RStudio on an RCAC cluster with resources sized to your data
* Load Bioconductor packages from the provided environment and install additional ones
* Submit an R script as a batch job for longer analyses

### Level

**Basic**. Basic familiarity with R is helpful.
