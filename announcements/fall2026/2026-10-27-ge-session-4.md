### Who Should Attend

Researchers who want production-quality pipelines for common assays such as RNA-seq and variant calling without writing them from scratch.

### What You’ll Learn

* What nf-core provides: curated, tested, community-maintained pipelines with documentation and test data
* How to build a samplesheet, choose parameters, and launch an nf-core pipeline on a cluster
* How profiles, containers, and resource settings keep runs within cluster limits

### By the End of the Session, You’ll

* Select an nf-core pipeline for an assay and assemble its required inputs
* Launch and monitor an nf-core run on a Slurm cluster
* Adjust profiles and resource requests when a run exceeds queue or memory limits

### Level

**Intermediate**. Session 3 (Nextflow fundamentals) or equivalent experience is recommended.
