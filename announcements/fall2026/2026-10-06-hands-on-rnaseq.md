### Who Should Attend

Researchers who have, or will soon have, bulk RNA-seq data and want to run the full analysis themselves on RCAC clusters, from raw reads to differential expression and enrichment.

### What You’ll Learn

* Quality control of raw reads and how to decide whether a dataset is ready for analysis
* Genome-based (STAR + featureCounts) and transcript-based (Kallisto) quantification, and when to choose each
* Differential expression with DESeq2 and gene set enrichment analysis

### By the End of the Workshop, You’ll

* Run an RNA-seq analysis from FASTQ files to a differential expression table on an RCAC cluster
* Choose between alignment-based and alignment-free quantification for your own data
* Produce and interpret DESeq2 results and enrichment plots you can carry into your own project

### Level

**Intermediate**. Basic command-line and R skills are expected.

**Required pre-work:** Complete the lesson’s [Summary and Setup](https://rcac-bioinformatics.github.io/rnaseq-analysis/) page before the workshop. SSH access to the cluster and data staging must be done before the session starts.
