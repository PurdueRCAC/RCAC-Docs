### Who Should Attend

Researchers who run multi-step analyses by hand or with shell scripts and want a workflow manager to handle scheduling, retries, and provenance for them.

### What You’ll Learn

* The building blocks of a Nextflow pipeline: processes, channels, and workflows
* How Nextflow runs the same pipeline on a laptop and on a Slurm cluster without changing the code
* Where the work directory, cache, and execution reports live, and how to use them when a run fails

### By the End of the Session, You’ll

* Read a Nextflow script and explain what each process consumes and produces
* Run a small pipeline on a cluster using a Slurm profile
* Resume a failed run from where it stopped instead of starting over

### Level

**Intermediate**. Comfort with the command line is expected; no prior Nextflow experience required.
