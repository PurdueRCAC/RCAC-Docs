### Who Should Attend

Researchers whose analysis does not match an existing pipeline and who want to turn their own scripts into a reusable, shareable workflow.

### What You’ll Learn

* How to break an existing shell, R, or Python script into Nextflow processes
* How to connect processes with channels and run many samples in parallel
* How to parameterize a workflow and package its software with modules or containers

### By the End of the Session, You’ll

* Convert a linear script into a small, working Nextflow workflow
* Run that workflow across many samples with a single command
* Hand the workflow to a collaborator who can run it unchanged

### Level

**Intermediate**. Sessions 3 and 4, or equivalent Nextflow experience, recommended.
