# Whatsnew plugins

Parameters of every plugin in the `whatsnew` group, from each plugin's manifest. Set them under **Extensions > Plugins** in the administrator interface.

## Whatsnew - Content (`plg_whatsnew_content`) { #whatsnew-content-plg-whatsnew-content }

Displays the latest articles

This plugin has no parameters.

## Whatsnew - Events (`plg_whatsnew_events`) { #whatsnew-events-plg-whatsnew-events }

Allows Searching of Events Component

This plugin has no parameters.

## Whatsnew - Knowledge Base (`plg_whatsnew_kb`) { #whatsnew-knowledge-base-plg-whatsnew-kb }

Allows Searching of Knowledge Base Component

This plugin has no parameters.

## Whatsnew - Publications (`plg_whatsnew_publications`) { #whatsnew-publications-plg-whatsnew-publications }

Displays the latest published Publications

This plugin has no parameters.

## Whatsnew - Resources (`plg_whatsnew_resources`) { #whatsnew-resources-plg-whatsnew-resources }

Allows searching of Resources component

This plugin has no parameters.

## Whatsnew - Wiki (`plg_whatsnew_wiki`) { #whatsnew-wiki-plg-whatsnew-wiki }

Allows Searching of Topic pages (wiki) Component

This plugin has no parameters.
