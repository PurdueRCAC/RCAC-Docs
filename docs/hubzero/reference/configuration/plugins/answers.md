# Answers plugins

Parameters of every plugin in the `answers` group, from each plugin's manifest. Set them under **Extensions > Plugins** in the administrator interface.

## Answers - Members (`plg_answers_members`) { #answers-members-plg-answers-members }

Answers plugin for adding ability to filter questions by member tags.

This plugin has no parameters.

## Answers - Tools (`plg_answers_tools`) { #answers-tools-plg-answers-tools }

Answers plugin for adding ability to filter questions by user's contributed tools.

This plugin has no parameters.
