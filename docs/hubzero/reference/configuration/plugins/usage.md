# Usage plugins

Parameters of every plugin in the `usage` group, from each plugin's manifest. Set them under **Extensions > Plugins** in the administrator interface.

## Usage - Domain Class (`plg_usage_domainclass`) { #usage-domain-class-plg-usage-domainclass }

Domain Class display for Usage component

This plugin has no parameters.

## Usage - Overview (`plg_usage_overview`) { #usage-overview-plg-usage-overview }

Overview display for Usage component

### Basic

| Parameter | Label | Type | Default | Description |
|---|---|---|---|---|
| `currentYear` | End Year | text | — | The most current date to end usage for. Leaving blank = 'now' |
| `currentMonth` | End Month | text | — | The most current date to end usage for. Leaving blank = 'now' |
| `message` | Message | textarea | — | A message to display to the users. |
