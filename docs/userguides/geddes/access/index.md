# Access

Access to the Geddes Composable Platform is handled via the RCAC web portal. When access is purchased, a Rancher project with your research group's name will be created and managers will be able to click to give users access, similar to how access is managed for community clusters. Geddes can be reached via the Rancher UI in a web browser or from the command line with `kubectl`.
