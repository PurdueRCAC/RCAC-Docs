# Groups and Sharing

Sharing in AnvilGPT operates through groups. A group is a named collection of users that can be used as the target for Knowledge Base or Model visibility settings. Groups are created and managed by the RCAC team.

To request a group:

1. Ensure all intended members already have an active AnvilGPT account.
2. Contact `rcac-help@purdue.edu` with the email addresses of the members and the name you want for the group.

Once the group is created, you can assign Knowledge Base or model visibility to that group. You do not need to decide all sharing details at the time of group creation. Membership and knowledge access can be configured after the group exists. Contact `rcac-help@purdue.edu` for any changes to group membership.
