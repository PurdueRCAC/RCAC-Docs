# File Transfer

{::if resource.name == Weber} In order to comply with regulatory security requirements, files may only be imported into the CUI ecosystem via the Gilbreth Inbox and exported from the ecosystem via Gilbreth Outbox. Other authorized systems within the CUI boundary may work with files stored on Gilbreth.  {::else} Gilbreth supports several methods for file transfer. Use the links below to learn more about these methods. {::/}
