# Can I access Fortress from Gilbreth?

Yes. While Fortress directories are not directly mounted on Gilbreth for performance and archival protection reasons, they can be accessed from Gilbreth front-ends and nodes using any of the recommended methods of [HSI, HTAR or Globus](/knowledge/fortress/storage/transfer).
