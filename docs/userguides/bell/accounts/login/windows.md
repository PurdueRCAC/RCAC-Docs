# Accounts on MAPS

If you are on a non-Windows system or a non-ONEPURDUE Windows machine, you can connect to MAPS via Remote Desktop. If you are connecting from off-campus, first you will need to connect to the [Purdue VPN](https://webvpn.purdue.edu/).

* Click the Windows/Start menu, click All Programs, click Accessories, then click Remote Desktop Connection. Mac users will need to download [Remote Desktop for Mac](https://apps.apple.com/us/app/microsoft-remote-desktop/id1295203466?mt=12). Linux users can install rdesktop from the distribution package manager.
* Once in the Remote Desktop application, click the Options button and enter the following information:
* Computer: maps01.rcac.purdue.edu or maps02.rcac.purdue.edu
* Username: ONEPURDUE\your\_username
* Click Connect.
* Once logged in, you may interactively access a variety of Geospatial software.
