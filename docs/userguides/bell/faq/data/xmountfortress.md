# Can I access Fortress from ${resource.name}?

Yes. While Fortress directories are not directly mounted on ${resource.name} for performance and archival protection reasons, they can be accessed from ${resource.name} front-ends and nodes using any of the recommended methods of [HSI, HTAR or Globus](/knowledge/fortress/storage/transfer).
