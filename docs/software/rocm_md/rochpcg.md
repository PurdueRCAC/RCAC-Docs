# rochpcg

[Back to ROCm containers](../rocm_catalog.md)

## Description

HPCG is a HPC benchmark intended to better represent computational and data access patterns that closely match a broad set of scientific workloads. This container implements the HPCG benchmark on top of AMD's ROCm platform.

## Homepage

[  https://hpcg-benchmark.org/](  https://hpcg-benchmark.org/)
