## Prerequisites

- An RCAC cluster account and the ability to log in ([HPC Orientation for Biologists](../../../lifesciences/guides/hpc-orientation.md))
- Comfort with basic R ([R Skills for Biological Data](../../../lifesciences/guides/r-data-wrangling.md))
- A laptop you can bring

## What you will be able to do afterward

- Run R/RStudio and single-cell R packages on RCAC clusters ([Installing R packages](../../../lifesciences/guides/r-packages.md))
- Load, quality-filter, and normalize a single-cell count matrix
- Cluster cells, visualize embeddings, and export figures and tables for downstream use
